عنوان H1 هو أهم عنوان في أي صفحة ويب - يخبر محركات البحث عن موضوع الصفحة الرئيسي. حالياً في موقع مكين، هناك مشكلتان رئيسيتان في هذا العنوان:

الصفحتان الرئيسيتان (العربية والإنجليزية) تحتويان على 7 عناوين H1 في كل صفحة بدلاً من عنوان واحد، و132 صفحة أخرى تحتوي على أكثر من H1 واحد، وأكثر من 2,300 صفحة تستخدم عناوين قصيرة جداً مثل "مكين 63" بدون وصف.

المطلوب: التأكد من أن كل صفحة تحتوي على عنوان H1 واحد فقط، واضح ووصفي ويحتوي على الكلمات المفتاحية المناسبة.

The H1 tag is the main heading of any page. It tells search engines what the page is about. Right now, Makeen has two H1 problems: 134 pages have multiple H1 tags competing with each other (including the two homepages which have 7 H1 tags each), and over 2,300 pages use H1 tags that are too short to be useful (just project names like "مكين 63" with no description).

🔍 The H1 Issues - Explained

Issue 1: Both Homepages Have 7 H1 Tags Instead of One

The Arabic homepage (/ar) and English homepage (/en) each have 7 H1 tags. These are the two most important pages on the entire site - they have a URL Rating of 97 (out of 100). Every page should have exactly one H1.

With 7 H1 tags competing on each homepage, search engines can't determine the main topic. The page's SEO focus gets diluted across all of them.

The English homepage (/en) has the same structure with 7 H1 tags: About Us, Make a Difference, Sustainable Projects, Explore Our Projects on the Map, Our Story in the Spotlight, Partners, Excellence in Real Estate Development.

The problem: Every section heading on the homepage is using <h1> instead of <h2>. None of these is the actual page title. We need to keep one descriptive H1 as the page title and change the rest to H2.

What's happening: the page template uses <h1> for section headings (like "مزايا المشروع" / "Project Features") instead of <h2> or <h3>. Only the page title should be H1.

Issue 3: 2,374 Pages Have H1 Tags That Are Too Short

The vast majority of pages (99.5% are property/unit pages) use the project name alone as the H1. A good H1 should describe what the page is about - not just state a name.

These H1s tell Google nothing about location, property type, or what makes each project unique.

⚡ Why This Matters for SEO

  • 7 competing H1 tags on each homepage - When Google sees 7 H1 tags on a single page, it cannot determine the main topic. The homepage's relevance gets diluted across all of them instead of clearly signaling what Makeen is about.
  • Multiple H1 tags - When a property page has 5 different H1s, Google can't determine the main topic. The page's relevance gets split across all of them.
  • Short/generic H1 tags - "مكين 63" tells Google nothing. It doesn't know if this is a residential compound in Riyadh, a commercial building, or a restaurant. We're missing the chance to rank for location-based and property-type keywords.
  • Competitive disadvantage - Competitors with descriptive H1s like "Luxury Villas in East Riyadh - Al Narjis District" will outrank a page with just "مكين 63".

🧩 The Simple Rule

Every page gets exactly one H1 tag. It should be descriptive, unique, and include the primary keyword for that page.

All other section headings on the page should use H2, H3, H4 - not H1.

🛠 What Needs to Be Done

Part 1 - Fix the homepage H1 tags (2 pages)

Both homepages currently have 7 <h1> tags each (all section headings are incorrectly using H1). Reduce them to a single descriptive H1 and change the remaining 6 to <h2>. The SEO team will provide the final H1 text.

Part 2 - Fix multiple H1 tags (132 pages)

In the property listing template and static page templates, find all <h1> tags that are used for section headings and change them to <h2> or <h3>. Only the main page title should remain as <h1>.

-- Before (wrong): multiple H1 tags in a property page -- <h1>مكين 63</h1> -- page title (correct as H1) <h1>مزايا المشروع</h1> -- section heading (should NOT be H1) <h1>الموقع</h1> -- section heading (should NOT be H1) -- After (correct): only one H1, rest are H2 -- <h1>مكين 63 - مجمع سكني في شرق الرياض</h1> -- descriptive H1 <h2>مزايا المشروع</h2> -- section heading <h2>الموقع</h2> -- section heading

Part 3 - Make H1 content dynamic and descriptive (2,374 pages)

The H1 on property/unit pages is currently pulling just the project name from the database. We need to enrich it. The H1 template should follow this pattern:

-- H1 pattern for property pages -- <h1>{project_name} - {property_type} في {location}</h1> -- Example output: -- <h1>مكين 63 - مجمع سكني في شرق الرياض</h1> -- English equivalent: -- <h1>Makeen 63 - Residential Compound in East Riyadh</h1>

Question for the dev team: Are "property type" and "location/district" stored as separate fields in the database? If so, we can build this dynamically. If not, we may need to add a dedicated H1 field to the CMS so the content team can fill it in per project.

💻 Quick Reference - Heading Hierarchy

For anyone on the team who's unsure about heading levels, here's how they should work on any page:

<h1> Page Title (only ONE per page) <h2> Major section <h3> Subsection <h3> Subsection <h2> Major section <h3> Subsection

Think of it like a document outline. H1 is the title of the book, H2 is a chapter, H3 is a section within a chapter. There's only one book title.
