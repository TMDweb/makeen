Project:asasmakeen.com

Date:May 20, 2026

ملخص المشكلة

ملف robots.txt يمنع مجلد /uploads/ بالكامل. المطلوب ببساطة هو حذف سطر المنع حتى تستطيع محركات البحث رؤية صور وملفات الصفحات العامة.

Issue: public upload assets are blocked by Disallow: /uploads/.

Fix: remove that disallow line. Do not add Allow rules for this; they are unnecessary when the folder is not disallowed.

🛠 Required Change

Remove this line from the main production robots.txt:

Remove
Disallow: /uploads/

Keep the rest of the protective rules for admin, dashboard, auth, API, and internal system paths.

Security check: before deploying, confirm /uploads/ only contains public media. If private files are mixed in, move them outside the public web path instead of using robots.txt as protection.

✅ Acceptance Criteria

  • https://asasmakeen.com/robots.txt no longer contains Disallow: /uploads/.
  • Example public upload assets return 200 in browser and curl checks.
  • Public /uploads/ assets are no longer blocked by robots.txt.
