Ticket #009 - /uploads/ Blocked by Robots.txt

Project:asasmakeen.com
Priority:High
Date:May 20, 2026
Source:Screaming Frog crawl

ملخص المشكلة

ملف robots.txt يمنع مجلد /uploads/ بالكامل، وهذا يحجب صور وملفات عامة مستخدمة داخل صفحات الموقع مثل صور .webp وملفات .svg.

المطلوب: السماح بالزحف لملفات الوسائط العامة داخل /uploads/، أو نقل الملفات العامة لمسار مسموح، مع إبقاء أي ملفات حساسة محجوبة.

Screaming Frog found that the production robots.txt blocks public upload assets. The rule Disallow: /uploads/ caused uploaded page images and SVG assets to be reported as Blocked by robots.txt.

This can prevent search engines from fetching important visual assets used on indexable pages, reducing image SEO, page understanding, and rendering confidence.

Important: do not simply expose private uploads. First confirm whether /uploads/ contains only public marketing/page media. If sensitive files live there, separate public media into a dedicated crawlable path.

🛠 Recommended Fix

Update robots.txt so public image/media uploads can be crawled while private or system uploads remain protected.

Current problematic pattern
User-agent: *
Disallow: /uploads/
Preferred target if uploads are public media
User-agent: *
Allow: /uploads/pages/
Allow: /uploads/projects/
Allow: /*.webp$
Allow: /*.svg$

Disallow: /admin/
Disallow: /dashboard/
Disallow: /api/

If /uploads/ mixes public and private files, create a safer structure such as /uploads/public/ for crawlable assets and keep private uploads outside the web root or blocked.

✅ Acceptance Criteria

After deployment, these checks should pass:

Validation commands
$ curl -s https://asasmakeen.com/robots.txt | grep -n "uploads"
# Public upload/image paths should not be globally blocked.

$ curl -I https://asasmakeen.com/uploads/pages/1744268921.webp
HTTP/2 200
content-type: image/webp

$ curl -I https://asasmakeen.com/uploads/pages/1739886361.svg
HTTP/2 200
content-type: image/svg+xml

Then rerun Screaming Frog and confirm uploaded public assets no longer appear under Response Codes → Internal Blocked by Robots.txt.
