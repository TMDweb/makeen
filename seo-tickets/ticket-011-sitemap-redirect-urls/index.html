ملخص المهمة

ملفات Sitemap على الموقع تتضمن 7 روابط تُعيد التوجيه (301/302) بدلاً من أن تكون صفحات حية (200). يجب أن يحتوي ملف Sitemap فقط على الصفحات النهائية المراد فهرستها؛ وجود روابط تحويل فيه يربك محركات البحث ويسبب مشاكل في الفهرسة.

الحل بسيط: حذف الروابط السبعة من ملفات Sitemap الثلاثة المذكورة بالأسفل. لا حاجة لاستبدالها لأن الصفحات الوجهة (destination) موجودة أصلاً في نفس الملفات. والأهم: تعديل مولّد الـ Sitemap بحيث يستبعد تلقائياً أي رابط لا يرجع 200.

The XML sitemaps on asasmakeen.com currently list 7 URLs that redirect (301/302) instead of resolving with a 200. A sitemap must list only the final, canonical pages we want crawled and indexed; redirecting entries waste crawl budget and cause indexability issues (Google treats them as "Page with redirect" and may delay or skip indexing the real targets).

Fix: remove the 7 redirecting URLs from the 3 sitemap files below. No replacements are needed - every destination URL is already listed in the same sitemap. Then harden the sitemap generator so it never emits a non-200 URL again.

🔎 Background

Six of the seven entries are the old blog URLs that were consolidated and 301'd in Ticket #010 (/76/ → /75/, /80/ + /179/ → /62/). The redirects were deployed correctly, but the sitemap generator still includes the old pages. The seventh is the bare root https://asasmakeen.com/ in sitemap-pages.xml, which 302s to /en.

🛡️ Prevent Recurrence

The sitemaps are generated dynamically, so removing the entries by hand is not enough. The generator must exclude any blog/page that has been merged, unpublished, or redirected. The simplest rule: a URL only enters the sitemap if it resolves 200 on the site itself (i.e., it is the live canonical version of its content). Whenever a future consolidation 301 is added (Ticket #010 is a running list), the old URL must drop out of the sitemap automatically.

✅ Verify

After deployment, the seven URLs must no longer appear in any sitemap, and every remaining sitemap URL must return 200. Pass = both commands below print 0 redirecting entries.

$ curl -s https://asasmakeen.com/sitemap-pages.xml \

  | grep -c -e 'asasmakeen.com/</loc>' -e '/d/76/' -e '/d/80/' -e '/d/179/'
