ملخص المهمة

هذه التذكرة هي القائمة الموحّدة لإعادة توجيهات 301 الناتجة عن دمج صفحات مكرّرة أو مترادفة في صفحة واحدة. كل عملية تحويل بند في قائمة تحقّق (checklist) بالأسفل؛ يُعلَّم على البند عند تنفيذه والتحقق منه، وتُضاف عمليات جديدة كبنود تباعاً.

المعيار الموحّد لكل تحويل: 301 دائم (وليس 302)، للعربي والإنجليزي معاً، مباشر إلى الوجهة بدون سلسلة تحويلات، مع تحديث أي روابط داخلية تشير إلى الرابط القديم.

This ticket is the running checklist of 301 redirects created whenever a duplicate or synonym page is merged into a single canonical page. It is not for one page: each consolidation is added as a new checklist item below, and checked off once it is deployed and verified.

Standard for every redirect: permanent 301 (not 302), for both ar and en, direct to the destination with no redirect chain, and update any internal links pointing at the old URL.

🔁 Redirect Checklist

Important - the Arabic URLs already redirect. On the Arabic side, each blog id already 301s from its old English slug to the current Arabic-slug page (e.g. /ar/blogs/d/80/riyadh-real-estate-investment-destination → /ar/blogs/d/80/الرياض-وجهة-الاستثمار-العقاري-الواعدة). The Old URL column below is the current live (200) page for each id, which is what must now redirect. For every consolidation: (1) 301 the live page to the target, and (2) update the existing old-slug redirect so it points straight to the new target, not to the old page, so there is no redirect chain. English pages keep the English slug as the live URL.

/76/ → /75/ (شقق تمليك → شقق للبيع)

Blog /76/ (شقق تمليك بالرياض) is a synonym duplicate of /75/ (شقق للبيع في الرياض): same buy intent in Saudi search, and near-zero performance (1 click / 19 impressions in 90 days). The /76/ body is merged manually into /75/ first, then the 301 is applied for both languages.
